# tradeHelper

Outil d'aide au trading orienté **swing / day trading**, sur **données ouvertes** (Yahoo Finance,
Binance, BCE), combinant **analyse technique** et **analyse fondamentale**, avec backtests
professionnels et interface graphique (Python + Tkinter).

> Avertissement : outil éducatif, pas un conseil en investissement.

- Voir le [guide utilisateur](guide-utilisateur.md) (lancement, onglets, raccourcis, GPU).
- Pour les agents qui reprennent le projet : [`AGENTS.md`](../AGENTS.md) (architecture, règles)
  et [`ROADMAP.md`](../ROADMAP.md) (feuille de route).

```bash
pip install --user -r requirements.txt
python3 run.py
```
